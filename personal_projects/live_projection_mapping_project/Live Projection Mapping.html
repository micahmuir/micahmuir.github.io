Live Projection Mapping

This was an experiment I did using TouchDesigner and a downward facing ToF camera. When an object reaches a certain height above the table, I masked everything below that threshold and ran edge detection to bound the projected images. It’s slow, with parallax error, but with 30 fps ToF camera running in real time with visual generation, it was an acceptable proof of concept.
